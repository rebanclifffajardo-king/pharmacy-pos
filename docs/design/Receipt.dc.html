Receipt rules

  • 58mm paper, 48mm printable — {{chars}} monospace columns, amounts right-aligned, item names wrap instead of overflowing.
  • Monochrome only; the logo is dithered to 1-bit at print time.
  • Print CSS hides the sidebar, header, buttons and modals — only the receipt node prints.
  • Reprints carry a “REPRINT” line and the original receipt number.
  • TIN, permit and serial fields are placeholders. Configure them for the pharmacy’s BIR registration; a generic template is not automatically compliant.
